# French retention — MVP spec

Personal web app. Not a tutor. I dump French notes; it helps me retain them.

## Loop (must work)
1. Dump notes anytime (by date)
2. Correct anything wrong + short why
3. Extract → Vocab (m/f + plural) · Grammar · Verbs (conjugations + phonetics)
4. SRS queue (forgot = sooner, remembered = later; mix across all notes)
5. Resend email in my hour window → link opens app
6. 10-card session: type → flip → remembered/forgot

## Screens
Home (dump + notes by date) · Note detail · Vocab/Verbs/Grammar · Quiz · Settings (email hours)

## Devices
MacBook Air 13" and iPhone 14 Pro Max (responsive)

## Stack intent
GitHub source of truth · Cursor agents later · Resend · traces on extract / SRS / email→quiz

## Out of scope for v1
Speaking/writing/listening tests · curriculum · design polish · heavy analytics

## Done when
I can dump a note, see corrections + extracts, get an email link, finish 10 cards, and SRS updates.
